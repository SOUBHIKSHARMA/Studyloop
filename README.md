# StudyLoop – AI-Powered Study Assistant

**StudyLoop** is an AI-powered study assistant that transforms study notes into interactive multiple-choice quizzes. It helps students practise active recall, evaluate their knowledge, understand concepts and track their learning progress.

🌐 **Live Demo:** https://studyloop-ai-study-assistant.ai.studio

💻 **GitHub Repository:** https://github.com/SOUBHIKSHARMA/Studyloop

---

## 🚀 Features

### 1. Interactive Dashboard
- View total quizzes completed.
- Track average quiz scores.
- Monitor saved study materials.
- View recent quiz activity.

### 2. Study Material Management
- Add notes using a text editor.
- Upload TXT files.
- Save, view and manage study materials.
- Automatically save data using browser localStorage.

### 3. AI Quiz Generator
- Generate MCQs from study notes using Google Gemini.
- Choose 5, 10 or 15 questions.
- Select Easy, Medium or Hard difficulty.
- Get four answer options for each question.
- Receive explanations for correct answers.

### 4. Interactive Quiz
- Answer questions one at a time.
- Navigate between questions.
- Track quiz progress.
- Submit answers and calculate scores.

### 5. Results and Quiz History
- View scores and percentage accuracy.
- Review correct and incorrect answers.
- Understand mistakes through explanations.
- Save completed quiz attempts for future reference.

### 6. AI Study Assistant
- Ask questions about saved study materials.
- Receive AI-generated explanations.
- Use selected notes as context for learning and revision.

## ⚙️ How It Works

1. Add or upload your study notes.
2. Select a study material.
3. Choose the number of questions and difficulty level.
4. Generate a quiz using AI.
5. Answer the questions and submit your quiz.
6. Review your score and explanations.
7. Track your progress through quiz history.

## 💻 Getting Started

### Prerequisites
- Node.js or Bun
- A compatible Gemini API configuration

### Installation

Clone the repository:

```bash
git clone https://github.com/SOUBHIKSHARMA/Studyloop.git
```

Navigate to the project directory:

```bash
cd Studyloop
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

**Note:** Configure any required Gemini credentials through the supported secure environment integration. Never commit API keys or secrets to GitHub. Check the project configuration for the exact environment variables and package manager.

---

## 💾 Data Storage

StudyLoop uses browser localStorage to save study materials and quiz history.

- Data remains available in the same browser after refreshing.
- Data is not automatically synchronized across devices.
- Clearing browser storage may remove saved information.
